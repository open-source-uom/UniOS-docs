# UniOS Landing Page

## Description
The UniOS Landing Page is a website in which the UniOS project is presented. It contains information about the operating system, the apps contained, the developer team who created and some frequently asked questions about the project. The user can also download the ISO of the operating system and visit the project's documentation website. 

## Installation guide
### As a user
Because is a website, users don't have to install it. If they want to visit the website, they can click here: https://unios-project.eu

### As a developer
As the developer, you have to follow this procedure:
- Make a fork of this repository
- Clone your fork locally

    `git clone git@github.com:yourGitHubUsername/UniOS-landing-page.git`

    _Note: You can use whichever url suits you._
- If you want to run the project, it's best to type this:

    `python3 -m http.server 8000`

    _Note: To run this command, you have to have python installed._
